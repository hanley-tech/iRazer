# Supported devices

Two tiers. **Tested** = verified on real hardware. **Experimental** = the
protocol is known (from the Razer/OpenRazer/OpenRGB database) but it has **not
been tested on macOS** — it may work, do nothing, or misbehave. Help us verify:
see [TESTING.md](TESTING.md).

The app also **detects** any Razer device you plug in (by USB PID) even before
it's verified, so you'll see it light up as *Detected · Experimental*.
